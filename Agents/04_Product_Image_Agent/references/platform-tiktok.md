## 标题与描述

| 项 | 规则 |
|---|---|
| 字符上限 | **未知**（US 与 SEA 都是）。不要采用未经卖家大学正文确认的 255 |
| 标题 | 准确、含品类与关键规格。品牌仅限已授权。不写促销、卖家链接、未授权 TikTok 标识 |
| 描述 | PH：不少于 **30** 个词，含安全信息与警示。其他站未核到 |
| 语言 | US 英语；SG / PH 英语；MY 英语或马来语；TH 泰语；ID 印尼语；VN 越南语 |

## 费用

| 站点 | 预设 | 说明 |
|---|---|---|
| US | `tiktok_us` 起步 **6%** | 卖家大学 2026-10-08 更新的类目表：多数类目 6%；指定珠宝子类与 Pre-Owned 为 5%。公式含买家运费，**不含税** |
| SG | 必须 `--commission` | 佣金按类目。交易费页面写 3.27%（GST inclusive，2025-10-01 起）。确认后用 `--extra-pct 3.27`，不要和佣金加在同一个数里 |
| MY | 必须 `--commission` | 2026-10-31 起按类目调整，Marketplace / Mall 不同 |
| ID | 必须 `--commission` | 课程页给出的平台佣金区间是 2.50%–12.20%，另有订单处理费等。区间不能直接当费率 |
| TH / VN / PH | 必须 `--commission` | 本次没有核到可引用的单一费率 |

达人佣金和广告都不在平台佣金里。

## 合规

不导流（电话、二维码、第三方链接）。不造评价、不造销量、不仿 TikTok 官方标识。禁售类目以各站 Seller University 原文为准，本卡不另编一份。
